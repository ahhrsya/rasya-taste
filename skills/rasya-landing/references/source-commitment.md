# Source Commitment

The source is the visual anchor that prevents generic output.

Bad source:

```text
modern, clean, premium, aesthetic, futuristic, elegant, minimal
```

Good source:

```text
a 1987 Sony product catalog
a Swiss rail timetable with strict tabular rhythm
a boutique skincare counter photographed on chrome and black glass
a Japanese stationery packaging insert
a Bloomberg terminal panel softened for a marketing site
a 1970s architecture monograph with oversized captions
```

The source must be specific enough to search for an image of it.

## Source Formula

Use one of these shapes:

```text
<year/era> + <artifact>
<place> + <material condition>
<publication> + <layout logic>
<product category> + <photography treatment>
<interface type> + <data/composition behavior>
```

## Lock Statement

Before coding, state:

```text
Reference Source:
Palette Rule:
Type System:
Layout Bet:
Motion Bet:
```

The layout bet should be a concrete composition choice:

```text
asymmetric split hero with product object breaking the grid
editorial masthead hero with horizontal product strip
sticky stack proof section with one pinned device mockup
scroll-driven material reveal using clipped product photography
```

The motion bet should explain purpose, not just style:

```text
Scroll reveals demonstrate the workflow sequence.
3D object rotation lets users inspect the product form.
Sticky stack turns features into a guided buying argument.
```
