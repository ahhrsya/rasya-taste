# Technical SaaS

Best for developer tools, AI workflow products, B2B platforms, infrastructure-adjacent SaaS, automation, analytics, and tools with a process.

## Source Ideas

- a Bloomberg terminal softened into a marketing page
- a lab notebook plus command palette
- a technical manual with productized diagrams
- an observability dashboard turned into a guided sales argument

## Palette

Use restrained neutrals with one precise accent. Monospace data may use semantic colors, but brand color stays consistent.

## Type

Grotesque display/body plus mono for data, code, IDs, metrics, and tabular values.

## Signature Moves

- Hero visual is a real workflow widget, not an abstract blob.
- Features pair claims with mini UI evidence.
- Integrations use a real node map only when integrations matter.
- Security/trust content is structured and specific.
- Docs/API snippets are readable.

## Motion

Use scroll-driven workflow progression, sticky UI states, command-palette interactions, or code/result transitions. GSAP is appropriate for pinned explanation sequences.

## Avoid

- fake code
- invented utility classes
- unreadable tiny dashboard screenshots
- dark mode by assumption
