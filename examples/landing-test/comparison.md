# Rasya vs Arya-Inspired Test

## Same Brief

`AuraCart`: AI ecommerce upsell tool for Shopify brands. Primary CTA: book a demo.

## Rasya Landing Output

The Rasya version optimizes for the commercial job first:

- primary CTA is visible immediately
- hero copy names the ecommerce outcome
- visual proof is a believable cart/upsell interface
- sections follow a conversion path: proof, mechanism, offer, pricing
- motion is restrained and tied to product understanding
- layout is designed to survive real product copy

## Arya-Inspired Output

The Arya-inspired version optimizes for aesthetic commitment first:

- visual source is more explicit: a 1985 chrome-and-neon retail terminal
- stronger atmosphere and texture
- more expressive hero composition
- less direct conversion scaffolding
- better for a memorable campaign or creative launch

## Takeaway

Rasya should keep Arya's source-commitment idea, but not inherit the whole
aesthetic-first priority stack. For everyday landing requests, Rasya should
start from the commercial job, then use source-based taste to make the page
distinctive.
